# ユビキタス言語定義

## 1. ドメイン用語の定義

| 用語 | 定義 |
|---|---|
| ログ | 自由記述形式のMarkdownファイル。書式の制約を設けず、作業内容・コマンド・仮説・検証結果などを時系列に記録する |
| タスク | ログの一部を参照する形で作成される、追跡対象の作業単位。ステータス・親子関係・停滞状態などを持つ |
| タスクID | タスクを一意に識別するID。同名タスクが複数存在する場合の区別のため、UI上ではタイトルと共に先頭部分(短縮ID)を併記する |
| 参照型タスク化 | ログ本文を移動・複製せず、マーカーによる参照でタスクとログを結びつける方式。対義概念は「抽出型」(ログから内容を切り出して移動する方式)で、本ツールは採用しない |
| マーカー | タスクが参照するログの範囲を示す、開始・終了一対のMarkdownコメント形式のアンカー |
| アンカー未接続 | マーカーが削除・欠落し、タスクが参照範囲のログ内容を復元できなくなった状態 |
| アンカーの再設定(再アンカー) | アンカー未接続になったタスクに対し、ログの新しい範囲へマーカーを挿入し直して参照先を張り替える操作 |
| 削除 | タスクをタスクツリーから取り除く操作。ログ本文・マーカーには一切触れない(マーカーは孤立した無害なコメントとして残る)。子タスクがある場合は、親への昇格か再帰的な削除かを選べる |
| フォーカス | 現在作業中として明示的に選択されているタスク。ステータスバーにパンくずとして表示され、新規タスク作成時の親のデフォルト決定に使われる。カーソル位置によって自動更新されることはなく、ツリーハイライトとは独立している |
| ツリーハイライト | カーソル位置に対応するタスクを、タスクツリー上で自動的に選択・表示(reveal)する表示専用の機能。フォーカスとは異なり、状態を変更したり新規タスクの親を決めたりすることはない |
| ルートタスク | 親を持たないタスク。Jiraチケットとの紐付けの起点となることが多いが、特別な種類のタスクではない |
| 部分木 | あるタスクと、その配下に連なる子孫タスク全体 |
| 停滞 | タスクの最終更新から、設定した時間閾値を超えて更新がない状態 |
| 要約 | タスク(またはその部分木)配下のタイトルとステータスを、階層構造が分かる形式で並べた、Jiraへの報告用テキスト。ログ本文の抜粋やAIによる自然文生成は行わない。投稿前にエディタでプレビュー・編集できる |
| 紐付け | タスクとJiraチケットを関連付けること。同じ部分木内でも、祖先と異なるチケットへの紐付けを許容する |
| 一方向連携 | タスクツリー側でどれだけ枝分かれしても、Jira側にサブタスクやチケットが新規作成されることはなく、要約コメントの投稿のみで連携する方式 |

## 2. ビジネス用語の定義

| 用語 | 定義 |
|---|---|
| スプリント | スクラムにおける固定サイクルの開発単位。本ツールが対象とする調査・トラブルシューティング作業は、このサイクルの外側で発生する不定形な作業として位置づけられる |
| チケット / work item | Jira上で管理される作業項目。本ツールにおいてはチケットの正(source of truth)であり続ける |
| 委託先コード | 社外の委託先から納品されたソースコード。動作確認・不具合調査が発生しやすい対象の一例 |

## 3. UI/UX用語の定義

| 用語 | 定義 |
|---|---|
| タスクツリービュー | VSCodeサイドバーに表示される、タスクの親子構造を表すTreeView |
| ステータスバー / パンくず | 現在フォーカス中のタスクの階層(祖先の連なり)を表示するVSCode下部のUI |
| インライン入力 | タスク化実行時、選択範囲から自動生成されたタイトル案をその場で確定・編集できるVSCode標準のQuickInput |

## 5. コード上の命名規則

ドメイン用語は、コード上では以下のように対応させる。表記のゆれ(例:「アンカー」と「マーカー」を混同して別の識別子で使う)が起きないよう、実装時はこの対応表に従う。

| ドメイン用語 | コード上の識別子 |
|---|---|
| タスク | `Task`(`src/models/task.ts`) |
| タスクID / 短縮ID | `Task.id`、UI表示は`formatTaskLabel`(`src/commands/pickTask.ts`)で先頭8文字を付与 |
| マーカー(開始・終了) | `anchorStartMarkerId` / `anchorEndMarkerId` |
| アンカー未接続 | `status`の値ではなく、`TaskTreeViewProvider`が描画時に`resolveAnchor`の解決可否から都度判定する状態(永続化しない) |
| アンカーの再設定(再アンカー) | `reanchorTask`(コマンド名)、`TaskStore.updateAnchor` |
| 削除 | `deleteTask`(コマンド名)、`TaskStore.delete` |
| フォーカス | `setFocus` / `clearFocus`(コマンド名) |
| ツリーハイライト | `CursorSyncController`、`TreeView.reveal()` |
| 停滞 | `stalled`(`status`の一値)、`StallDetector`(サービス名) |
| 要約 | `buildSummary`関数(`src/services/summaryGenerator.ts`)、`pushSummaryToJira`(コマンド名) |
| 紐付け | `jiraIssueKey`(タスクの属性)、`linkJiraIssue`(コマンド名)、`TaskStore.setJiraLink` / `findNearestJiraLinkedTask` |
| 部分木を祖先の要約に含めるか | `includeInAncestorSummary` |
| Jira接続設定 | `getJiraClient`(`src/commands/getJiraClient.ts`)、`setJiraApiToken`(コマンド名)、`taskLog.jira.baseUrl` / `taskLog.jira.email`(拡張設定) |
